# Wang Ops Scripts

老王的日常运维脚本集。

## 脚本列表

| 脚本 | 用途 |
|------|------|
| `quick_connect.sh` | 快速远程连接（SSH/RDP/VNC） |
| `system_check.sh` | 系统状态快速检查 |

## 使用方法

```bash
# 快速连接
./scripts/quick_connect.sh wang2025
./scripts/quick_connect.sh sgp

# 系统检查
./scripts/system_check.sh
```

## 设备清单

| 设备 | 地址 | 用途 |
|------|------|------|
| wang2025 | wang2025.lan | 本地 NAS |
| sgp | $SGP_HOST | 新加坡服务器 |
